# 02 — Searching and Sorting

Searching: linear search, binary search, lower/upper bound, rotated-array search, binary search on answer.

Sorting: selection, insertion, bubble, merge, quick, heap, counting, radix and bucket sort.

Binary search: O(log n) time and O(1) iterative auxiliary space.
Merge sort: O(n log n) time and O(n) auxiliary space.
Quick sort: average O(n log n), worst O(n²).

Study stability, in-place sorting, pivot selection and adversarial inputs.
