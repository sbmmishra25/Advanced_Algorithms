# 07 — Graph Algorithms

Representations: adjacency matrix, adjacency list and edge list.

Traversal: BFS, DFS, connected components, bipartite checking and cycle detection.

Structure: topological sorting, SCC, articulation points, bridges, Eulerian paths and MST.

BFS and DFS run in O(V+E) with adjacency lists.

Advanced: graph decomposition, matching, dynamic graphs and spectral methods.
