## Quality standard

For major algorithms the target format is:

**Problem → intuition → formal model → pseudocode → correctness proof → complexity → implementation → worked example → edge cases → common mistakes → applications → practice → advanced extension.**

### Important scope note

No repository can literally contain every algorithm ever published: variants, domain-specific methods and new research algorithms continue to appear. This project therefore targets **broad, systematic coverage of the major algorithm families and their important variants**, while preserving room for specialized additions.
