# 06 — Backtracking and Branch & Bound

Backtracking incrementally builds a candidate and prunes partial candidates that cannot produce valid solutions.

Topics: N-Queens, subsets, permutations, combination sum, graph coloring and Hamiltonian cycle.

Branch and Bound uses bounds to eliminate branches that cannot improve the best known solution.

Applications: 0/1 knapsack, TSP and assignment problem.

Worst-case complexity is often exponential; pruning effectiveness depends on the problem and bound quality.
