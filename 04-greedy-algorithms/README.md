# 04 — Greedy Algorithms

A greedy algorithm makes a locally best feasible choice and requires a proof that this choice can be extended to an optimal solution.

Topics: activity selection, fractional knapsack, job sequencing with deadlines, Huffman coding, Kruskal, Prim, Dijkstra and interval scheduling.

Proof patterns: exchange argument, cut property and staying-ahead argument.

For every greedy method document the greedy choice, feasibility, optimal substructure, proof and complexity.
