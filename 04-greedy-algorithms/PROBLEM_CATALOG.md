# Greedy Algorithms — Problem Catalog

- Interval scheduling
- Weighted interval scheduling (important counterexample to naive greedy; solved by DP)
- Job sequencing with deadlines
- Deadline scheduling
- Minimum number of platforms
- Meeting rooms
- Task scheduling

## Packing and selection

## Graphs
- Kruskal MST
- Prim MST
- Dijkstra
- Boruvka MST
- Reverse-delete MST
- Matroid greedy

## Optimization
- Set cover approximation
- Vertex cover approximation
- Metric TSP approximation
- Scheduling approximations
- Load balancing heuristics

## Proof checklist
For each problem explain:
1. greedy choice
2. exchange/staying-ahead argument
3. optimal substructure
4. counterexamples to tempting wrong strategies
5. complexity

## Practice ladder
Beginner: activity selection, fractional knapsack.
Intermediate: job sequencing, Huffman, MST.
Advanced: matroids, approximation and scheduling.
