# Dynamic Programming — Problem Catalog

## 1D DP
Fibonacci, climbing stairs, house robber, maximum subarray, decode ways.

## Knapsack
0/1 knapsack, unbounded knapsack, bounded knapsack, subset sum, partition, target sum, coin change, rod cutting.

## Sequence DP
LIS, LCS, LCSubstring, edit distance, distinct subsequences, wildcard matching.

## Grid DP
unique paths, minimum path sum, obstacle paths, grid collection, falling path.

## Interval DP
matrix-chain multiplication, burst balloons, optimal BST, palindrome partitioning, merge stones.

## String DP
edit distance, word break, regex-style matching, interleaving strings.

## Tree DP
maximum independent set, diameter variants, vertex cover, rerooting DP.

## DAG DP
longest path in DAG, path counting, scheduling on DAGs.

## Bitmask DP
TSP, assignment, Hamiltonian path, subset partition.

## Digit DP
count numbers with digit constraints, sum of digits, no-adjacent-equal digits, forbidden patterns.

## Advanced optimization
Divide-and-conquer optimization, Knuth optimization, convex hull trick, Li Chao tree, monotone queue optimization, bitset DP.

For every problem record: state, transition, base case, order, complexity, reconstruction and why greedy fails when it does.
