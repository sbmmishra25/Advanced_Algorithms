# 05 — Dynamic Programming

Use DP when subproblems overlap and optimal substructure exists.

Workflow: define state, transition, base cases, memoization or tabulation, state complexity and reconstruction.

Topics: Fibonacci, 0/1 knapsack, unbounded knapsack, coin change, LIS, LCS, edit distance, matrix-chain multiplication, rod cutting, interval DP, tree DP, digit DP and bitmask DP.

Example: 0/1 knapsack has O(nW) time and can use O(W) memory when reconstruction is unnecessary.

Advanced: state compression, monotone optimization, divide-and-conquer DP optimization and bitset acceleration.
