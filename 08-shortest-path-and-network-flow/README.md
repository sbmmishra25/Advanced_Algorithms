# 08 — Shortest Paths and Network Flow

Shortest paths: BFS, Dijkstra, Bellman-Ford, Floyd-Warshall, DAG shortest paths and Johnson's algorithm.

Flow: Ford-Fulkerson, Edmonds-Karp, Dinic, min-cut/max-flow and bipartite matching.

Choose by assumptions: BFS for unweighted graphs, Dijkstra for non-negative weights, Bellman-Ford for negative edges, Floyd-Warshall for small dense all-pairs problems and DAG relaxation for acyclic graphs.
