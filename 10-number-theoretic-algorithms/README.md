# 10 — Number-Theoretic Algorithms

Topics: Euclidean GCD, extended Euclidean algorithm, fast exponentiation, sieve of Eratosthenes, segmented sieve, modular arithmetic, modular inverse, CRT, primality testing and factorization.

Euclidean GCD runs in O(log min(a,b)).

Advanced: Miller-Rabin, Pollard Rho and number-theoretic transforms.
