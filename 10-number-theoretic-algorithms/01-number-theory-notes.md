# Number-Theoretic Algorithms

## Core arithmetic
- Euclidean algorithm for gcd.
- Extended Euclidean algorithm for Bezout coefficients.
- Binary GCD.
- Fast modular exponentiation.
- Modular inverse.
- Chinese Remainder Theorem.

## Prime algorithms
- Sieve of Eratosthenes.
- Segmented sieve.
- Trial division.
- Miller-Rabin primality testing.
- Integer factorization methods, with Pollard Rho as an advanced probabilistic technique.

## Combinatorial arithmetic
- Factorials and inverse factorials modulo a prime.
- Binomial coefficients.
- Lucas theorem.
- Inclusion-exclusion.
- Mobius function and sieve.
- Euler totient and linear sieve.

## Applications
Cryptography, hashing, combinatorics, competitive programming, randomized algorithms, and computational number theory.

## Complexity discipline
For integer algorithms, distinguish the numerical value of n from its bit length log n. A polynomial in n may be exponential in the input length.
