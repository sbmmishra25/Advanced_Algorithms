# Algorithms: Definition, Characteristics, Types and Applications

## 1. Definition

An algorithm is a finite, precise and effective sequence of computational steps that transforms valid input into the required output and terminates under its stated assumptions.

### Classical characteristics
1. **Input** — zero or more well-defined inputs.
2. **Output** — at least one well-defined result.
3. **Definiteness** — every step is unambiguous.
4. **Finiteness** — execution terminates for every valid instance.
5. **Effectiveness** — each operation is sufficiently basic to be executable.
6. **Correctness** — output satisfies the problem specification.
7. **Generality** — solves a class of instances, not only one example.

## 2. Algorithm vs program

An algorithm is the problem-solving method. A program is one implementation of that method in a programming language.

Example: binary search is an algorithm; a Python function implementing binary search is a program.

## 5. Applications

Algorithms power search engines, databases, operating systems, compilers, networks, routing, cryptography, compression, scheduling, recommendation systems, scientific computing, AI/ML, robotics, bioinformatics, finance, logistics, cybersecurity and quantum computing.

## 6. A complete problem-solving workflow

1. Read constraints.
2. Formalize input/output.
3. Identify the computational model.
4. Build a brute-force baseline for small cases.
5. Identify structure.
6. Select a design paradigm.
7. Prove correctness.
8. Analyze time/space.
9. Implement.
10. Test edge cases.
11. Benchmark against a baseline.
12. Document assumptions and limitations.
