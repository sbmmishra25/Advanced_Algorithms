# Advanced Algorithms — Master Roadmap

This repository is intentionally broader than a single university syllabus. It is organized as a long-term reference from first principles to advanced and research-oriented algorithmics.

## Learning levels

### Level 0 — What an algorithm is
- Problem, instance, input, output, constraints
- Algorithm vs program vs heuristic
- Correctness, termination, invariants
- Deterministic and nondeterministic models
- RAM model and cost assumptions

### Level 1 — Analysis
- Five standard asymptotic notations: O, Ω, Θ, o, ω
- Growth rates and dominance
- Best, worst, average and amortized analysis
- Recurrences
- Substitution, recursion-tree and Master methods
- Akra–Bazzi and advanced recurrence analysis
- Space complexity and lower bounds

### Level 2 — Core design paradigms
- Brute force
- Divide and conquer
- Decrease and conquer
- Transform and conquer
- Greedy
- Dynamic programming
- Backtracking
- Branch and bound
- Randomization
- Approximation
- Meet-in-the-middle
- Bitmask/state compression
- Sweep line
- Two pointers/sliding window
- Binary search on answer

### Level 3 — Fundamental algorithm families
Searching, sorting, hashing, selection, graph traversal, shortest paths, MST, flow, matching, strings, number theory and geometry.

### Level 4 — Advanced
Advanced data structures, randomized algorithms, approximation algorithms, computational geometry, online/streaming/external-memory algorithms, parallel algorithms, parameterized algorithms and complexity theory.

### Level 5 — Research
Quantum algorithms, learning-augmented algorithms, dynamic graphs, succinct structures, algorithmic game theory, distributed algorithms and open research problems.

## Topic-file standard

Each major topic should answer:
**What? Why? How? Proof? Complexity? When to use? When not to use? Example? Code? Practice? Advanced extension?**

The word "all" in algorithmics is interpreted as a comprehensive taxonomy: algorithms continue to evolve, and some variants are specialized, historical, experimental or impractical. The repository therefore aims for broad coverage rather than claiming a literally finite list of every algorithm ever published.
