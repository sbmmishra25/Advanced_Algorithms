# Contributing

Useful contributions include clearer explanations, corrected proofs, Python or C++ implementations, worked examples, tests, complexity analysis, and counterexamples for incorrect approaches.

## Quality checklist
- Define the problem and constraints.
- Explain intuition.
- Give pseudocode or a precise procedure.
- Include a correctness argument.
- State time and space complexity.
- Include edge cases.
- Add runnable code where appropriate.
- Avoid unexplained constants.
- Keep examples reproducible.
