# 15 — Advanced Problem Solving

Patterns: binary search on answer, two pointers, sliding window, prefix sums, difference arrays, sweep line, coordinate compression, bit manipulation, meet-in-the-middle, state-space search, graph plus DP and greedy plus data structures.

Workflow: formalize constraints, identify bottleneck, establish invariant, design, prove, analyze, implement, test edge cases and compare against a brute-force oracle on small inputs.
