# Master Algorithm Problem List

Use this as a progression rather than attempting everything at once.

## Foundation
Linear search, binary search, basic sorts, GCD, sieve, recursion, prefix sums.

## Core
Merge sort, quicksort, heap, BFS, DFS, topological sort, DSU, MST, Dijkstra, activity selection, knapsack, LCS.

## Intermediate
Job sequencing, Huffman, Bellman-Ford, Floyd-Warshall, SCC, bridges, KMP, rolling hash, segment tree, Fenwick tree, N-Queens, subset DP.

## Advanced
Dinic, bipartite matching, min-cost flow, heavy-light decomposition, centroid decomposition, suffix array, suffix automaton, Aho-Corasick, digit DP, rerooting DP, meet-in-the-middle, computational geometry.

## Research-oriented
Parameterized algorithms, online algorithms, streaming, external-memory algorithms, parallel algorithms, randomized algorithms, approximation, quantum algorithms, learning-augmented algorithms, dynamic graph algorithms.

For each solved problem store: statement, constraints, idea, proof, complexity, implementation, tests and alternative solutions.
