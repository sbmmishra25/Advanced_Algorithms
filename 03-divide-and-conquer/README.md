# 03 — Divide and Conquer

Method: divide into smaller subproblems, solve recursively, combine.

Topics: merge sort, quicksort, binary search, maximum subarray, counting inversions, closest pair of points and Strassen matrix multiplication.

Example recurrence: T(n)=2T(n/2)+O(n) gives O(n log n).

Research extension: compare algorithmic complexity with cache behavior and practical performance.
